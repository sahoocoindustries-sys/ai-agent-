# RUDRA Specification

RUDRA is a portable, consent-based, offline-first AI-assisted diagnostic and defensive-security system.

## Key Attributes
- **Target Storage**: ~8 GB Portable USB Drive
- **Primary OS Target**: Windows 11 / 10 (with extensible cross-platform abstraction for Linux/macOS/mobile companions)
- **Primary Technology Stack**: Python 3.13+, FastAPI, React + TypeScript + Vite, SQLite
- **Architecture Status**:
  - **Phase 0 Foundation**: `IMPLEMENTED` & `VERIFIED`
  - **Phase 1 Portable Core (CN, UP, CP, ST, AX)**: `IMPLEMENTED` & `VERIFIED`
  - **Phase 2+ Diagnostics & AI**: `NOT_IMPLEMENTED` / `PLANNED`
